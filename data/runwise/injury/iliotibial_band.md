# 髂胫束综合征

## 核心概念

髂胫束综合征（ITBS）是跑者最常见的膝外侧疼痛之一，约占跑步损伤的 12%。

### 解剖基础

**髂胫束**：从髋部（阔筋膜张肌和臀大肌）延伸至胫骨外侧的一条厚韧带。

**功能**：
- 稳定膝关节
- 协助髋关节外展
- 跑步时反复摩擦股骨外上髁

### 发病机制

跑步过程中，髂胫束在膝关节屈伸时反复前后滑动。当髂胫束过紧或摩擦点压力过大时，引发炎症和疼痛。

**疼痛位置**：膝关节外侧，约在膝线上方 2-3cm 处。

## 常见问题

### 问题一：为什么会得 ITBS？

**主要风险因素**：

| 因素 | 说明 |
|------|------|
| 臀中肌无力 | 髋稳定性差，髂胫束代偿 |
| 髂胫束过紧 | 摩擦点压力增大 |
| 过度内旋 | 足外翻导致膝关节内侧压力增加 |
| 跑量增加过快 | 超过组织适应能力 |
| 下坡跑过多 | 膝关节屈曲角度增大，摩擦增加 |
| 穿旧鞋 | 缓冲不足，冲击增大 |

### 问题二：怎么判断是 ITBS？

**典型症状**：
- 疼痛在膝关节外侧
- 跑步 2-3km 后开始疼痛
- 下坡跑时疼痛加重
- 休息后缓解，再跑又痛
- 屈膝 30 度左右最痛（Noble 试验阳性）

**鉴别诊断**：
- 跑者膝：髌骨下方或内侧疼痛
- 外侧半月板损伤：关节间隙压痛，可能有交锁
- 腘肌腱炎：膝关节后外侧疼痛

### 问题三：还能继续跑吗？

**原则**：
- 疼痛评分 1-3/10：可继续跑，但减少跑量
- 疼痛评分 4-6/10：减量 50%，避免下坡
- 疼痛评分 7-10/10：停止跑步，改为交叉训练

## 建议方案

### 急性期处理（1-2 周）

1. **休息**：停止跑步或大幅减量
2. **冰敷**：每次 15-20 分钟，每天 2-3 次
3. **非甾体抗炎药**：如布洛芬（遵医嘱）
4. **避免诱发因素**：不下坡跑、不跑弯道

### 康复训练

**髂胫束放松**：

使用泡沫轴：
- 侧卧，泡沫轴置于大腿外侧
- 从髋部滚动至膝上方（不要直接滚膝关节）
- 每次滚动 30-60 秒，每天 2-3 次

**臀中肌强化**：

1. **蚌式开合**：
   - 侧卧，膝弯曲 90 度
   - 保持双脚并拢，上方膝盖向上打开
   - 每组 15-20 次，做 3 组

2. **侧抬腿**：
   - 侧卧，下方腿弯曲，上方腿伸直抬起
   - 每组 15-20 次，做 3 组

3. **单腿臀桥**：
   - 仰卧，一腿弯曲踩地，另一腿伸直
   - 抬起臀部至身体成直线
   - 每组 10-15 次，做 3 组

**髋屈肌拉伸**：

- 弓步姿势，后膝着地
- 身体前倾，感受髋前侧拉伸
- 每侧保持 30 秒，做 3 次

### 恢复跑步

**标准**：
- 无痛完成 30 分钟快走
- 单腿下蹲无痛
- Noble 试验阴性

**回归计划**：

| 阶段 | 内容 | 时长 |
|------|------|------|
| 1 | 快走 30min | 3-5 天 |
| 2 | 走跑结合 30min（跑 2min/走 1min） | 1 周 |
| 3 | 轻松跑 5km | 1 周 |
| 4 | 正常训练 | - |

## 注意事项

1. **不要只做拉伸**：臀中肌无力是根本原因，必须加强力量训练
2. **避免过度按摩**：髂胫束炎症期按摩可能加重症状
3. **检查跑鞋**：磨损严重的跑鞋会加重问题
4. **注意跑道方向**：单向跑时，每圈转向会改变膝关节受力

## 大学生场景案例

### 案例一：田径场单向跑导致 ITBS

小张，大二，每天在田径场顺时针跑 10 圈。

**问题**：田径场弯道外侧腿（右腿）受力更大，长期导致右膝外侧 ITBS。

**解决**：
- 每次训练交替方向（顺时针/逆时针）
- 减少田径场训练，增加公园直线跑
- 加强臀中肌训练

### 案例二：跑量突增引发 ITBS

小李，大三，为备战半马，周跑量从 30km 骤增至 50km。

**结果**：第三周出现左膝外侧疼痛，确诊 ITBS。

**处理**：
- 停跑 2 周，改为游泳和骑车
- 每天泡沫轴放松 + 臀中肌训练
- 恢复后跑量从 20km 开始，每周增加不超过 10%

## FAQ

**Q：ITBS 会自愈吗？**
A：轻度可能，但多数需要主动康复。不处理容易反复发作。

**Q：泡沫轴滚髂胫束很痛正常吗？**
A：正常，但疼痛应在可忍受范围。如果剧痛难忍，说明炎症较重，先冰敷休息。

**Q：ITBS 和跑者膝有什么区别？**
A：ITBS 是膝外侧疼痛，跑者膝是髌骨周围疼痛。两者病因和处理方法不同。

**Q：多久能恢复跑步？**
A：轻度 2-4 周，中度 4-8 周，重度可能需要 2-3 个月。配合康复训练可加速恢复。
