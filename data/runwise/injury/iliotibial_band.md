# 髂胫束综合征

## 核心概念

髂胫束综合征（ITBS）是跑者最常见的膝外侧疼痛之一，约占跑步损伤的 12%。

### 解剖基础

**髂胫束**：从髋部（阔筋膜张肌和臀大肌）延伸至胫骨外侧的一条厚韧带。

**功能**：
- 稳定膝关节
- 协助髋关节外展
- 跑步时反复摩擦股骨外上髁

### 发病机制

跑步过程中，髂胫束在膝关节屈伸时反复前后滑动。当髂胫束过紧或摩擦点压力过大时，引发炎症和疼痛。

**疼痛位置**：膝关节外侧，约在膝线上方 2-3cm 处。

## 常见问题

### 问题一：为什么会得 ITBS？

**主要风险因素**：

| 因素 | 说明 |
|------|------|
| 臀中肌无力 | 髋稳定性差，髂胫束代偿 |
| 髂胫束过紧 | 摩擦点压力增大 |
| 过度内旋 | 足外翻导致膝关节内侧压力增加 |
| 跑量增加过快 | 超过组织适应能力 |
| 下坡跑过多 | 膝关节屈曲角度增大，摩擦增加 |
| 穿旧鞋 | 缓冲不足，冲击增大 |

### 问题二：怎么判断是 ITBS？

**典型症状**：
- 疼痛在膝关节外侧
- 跑步 2-3km 后开始疼痛
- 下坡跑时疼痛加重
- 休息后缓解，再跑又痛
- 屈膝 30 度左右最痛（Noble 试验阳性）

**鉴别诊断**：
- 跑者膝：髌骨下方或内侧疼痛
- 外侧半月板损伤：关节间隙压痛，可能有交锁
- 腘肌腱炎：膝关节后外侧疼痛

### 问题三：还能继续跑吗？

**原则**：
- 疼痛评分 1-3/10：可继续跑，但减少跑量
- 疼痛评分 4-6/10：减量 50%，避免下坡
- 疼痛评分 7-10/10：停止跑步，改为交叉训练

## 建议方案

### 急性期处理（1-2 周）

1. **休息**：停止跑步或大幅减量
2. **冰敷**：每次 15-20 分钟，每天 2-3 次
3. **非甾体抗炎药**：如布洛芬（遵医嘱）
4. **避免诱发因素**：不下坡跑、不跑弯道

### 康复训练

**髂胫束放松**：

使用泡沫轴：
- 侧卧，泡沫轴置于大腿外侧
- 从髋部滚动至膝上方（不要直接滚膝关节）
- 每次滚动 30-60 秒，每天 2-3 次

**臀中肌强化**：

1. **蚌式开合**：
   - 侧卧，膝弯曲 90 度
   - 保持双脚并拢，上方膝盖向上打开
   - 每组 15-20 次，做 3 组

2. **侧抬腿**：
   - 侧卧，下方腿弯曲，上方腿伸直抬起
   - 每组 15-20 次，做 3 组

3. **单腿臀桥**：
   - 仰卧，一腿弯曲踩地，另一腿伸直
   - 抬起臀部至身体成直线
   - 每组 10-15 次，做 3 组

**髋屈肌拉伸**：

- 弓步姿势，后膝着地
- 身体前倾，感受髋前侧拉伸
- 每侧保持 30 秒，做 3 次

### 恢复跑步

**标准**：
- 无痛完成 30 分钟快走
- 单腿下蹲无痛
- Noble 试验阴性

**回归计划**：

| 阶段 | 内容 | 时长 |
|------|------|------|
| 1 | 快走 30min | 3-5 天 |
| 2 | 走跑结合 30min（跑 2min/走 1min） | 1 周 |
| 3 | 轻松跑 5km | 1 周 |
| 4 | 正常训练 | - |

## 注意事项

1. **不要只做拉伸**：臀中肌无力是根本原因，必须加强力量训练
2. **避免过度按摩**：髂胫束炎症期按摩可能加重症状
3. **检查跑鞋**：磨损严重的跑鞋会加重问题
4. **注意跑道方向**：单向跑时，每圈转向会改变膝关节受力

## 大学生场景案例

### 案例一：田径场单向跑导致 ITBS

小张，大二，每天在田径场顺时针跑 10 圈。

**问题**：田径场弯道外侧腿（右腿）受力更大，长期导致右膝外侧 ITBS。

**解决**：
- 每次训练交替方向（顺时针/逆时针）
- 减少田径场训练，增加公园直线跑
- 加强臀中肌训练

### 案例二：跑量突增引发 ITBS

小李，大三，为备战半马，周跑量从 30km 骤增至 50km。

**结果**：第三周出现左膝外侧疼痛，确诊 ITBS。

**处理**：
- 停跑 2 周，改为游泳和骑车
- 每天泡沫轴放松 + 臀中肌训练
- 恢复后跑量从 20km 开始，每周增加不超过 10%

## FAQ

**Q：ITBS 会自愈吗？**
A：轻度可能，但多数需要主动康复。不处理容易反复发作。

**Q：泡沫轴滚髂胫束很痛正常吗？**
A：正常，但疼痛应在可忍受范围。如果剧痛难忍，说明炎症较重，先冰敷休息。

**Q：ITBS 和跑者膝有什么区别？**
A：ITBS 是膝外侧疼痛，跑者膝是髌骨周围疼痛。两者病因和处理方法不同。

**Q：多久能恢复跑步？**
A：轻度 2-4 周，中度 4-8 周，重度可能需要 2-3 个月。配合康复训练可加速恢复。

### 疼痛评估量表

使用 0-10 数字疼痛量表评估膝外侧疼痛程度，结合"红绿灯"系统指导训练决策。ITBS 的特点是"跑 2-3km 后才出现疼痛"，因此评估要结合跑步距离。

| 评分 | 疼痛描述 | 红绿灯 | 行动指南 |
|------|----------|--------|----------|
| 0 | 完全无痛 | 🟢 绿灯 | 正常训练，保持臀中肌力量训练 |
| 1 | 长距离后膝外侧轻微紧绷 | 🟢 绿灯 | 正常训练，跑后泡沫轴放松 |
| 2 | 跑 5km 以上出现轻微疼痛 | 🟢 绿灯 | 可继续，监控疼痛是否加重 |
| 3 | 跑 3-5km 出现疼痛，不影响配速 | 🟢 绿灯 | 减量，避免下坡和弯道 |
| 4 | 跑 2-3km 即痛，轻微影响步态 | 🟡 黄灯 | 减量 50%，仅平直路面轻松跑 |
| 5 | 疼痛迫使放慢配速 | 🟡 黄灯 | 停速度训练，加强臀中肌训练 |
| 6 | 跑后疼痛持续数小时 | 🟡 黄灯 | 改走跑结合，每天泡沫轴 + 臀肌训练 |
| 7 | 跑 1km 内即痛，无法继续 | 🔴 红灯 | 停止跑步，改为交叉训练 |
| 8 | 上下楼梯时膝外侧痛 | 🔴 红灯 | 完全休息，冰敷，建议就医 |
| 9 | 走路即痛，膝关节活动受限 | 🔴 红灯 | 就医排除半月板等其他问题 |
| 10 | 剧痛无法负重，伴肿胀交锁 | 🔴 红灯 | 急诊就医，排除半月板撕裂 |

**使用建议**：记录"开始疼痛的距离"是 ITBS 的重要指标，距离延长说明好转，距离缩短说明加重。

### 鉴别诊断速查

| 特征 | 髂胫束综合征 | 跑者膝 | 外侧半月板损伤 | 髌腱炎 | 腘肌腱炎 |
|------|--------------|--------|----------------|--------|----------|
| 疼痛位置 | 膝外侧（膝线上 2-3cm） | 髌骨周围/下方 | 外侧关节间隙 | 髌骨下极 | 膝后外侧 |
| 疼痛性质 | 锐痛、刺痛、灼烧感 | 钝痛、酸胀 | 交锁、弹响伴痛 | 跳跃时痛 | 下坡跑痛 |
| 出现时机 | 跑 2-3km 后 | 跑步中逐渐加重 | 扭转、深蹲时 | 跳跃、上下楼 | 屈膝下坡 |
| 压痛点 | 股骨外上髁 | 髌骨后/下 | 外侧关节间隙 | 髌骨下极腱 | 股骨外侧髁后 |
| 休息后 | 缓解，再跑又痛 | 部分缓解 | 不一定缓解 | 部分缓解 | 部分缓解 |
| 关节交锁 | 无 | 无 | 可有 | 无 | 无 |
| 肿胀 | 通常无 | 通常无 | 常有积液 | 可有局部肿 | 通常无 |

**关键鉴别**：ITBS 与跑者膝都属"过度使用"，但 ITBS 是膝外侧"明确一点的锐痛"且跑 2-3km 后才出现，跑者膝是髌骨"周围弥漫性钝痛"且久坐后站起明显（电影院征）。

### 预防性力量训练计划

针对臀中肌、髋外展肌群和核心稳定性的 4 周预防计划。臀中肌无力是 ITBS 的根本原因。

| 周次 | 频率 | 训练内容 | 组数×次数 |
|------|------|----------|-----------|
| 第1周 | 每周 3 次 | 蚌式开合 + 侧抬腿 + 仰卧臀桥 | 各 3×15 |
| 第1周 | 每周 2 次 | 泡沫轴放松大腿外侧 + 髋屈肌拉伸（30 秒/侧） | 3 次 |
| 第2周 | 每周 3 次 | 蚌式开合（加弹力带）+ 单腿臀桥 + 侧向蟹步走 | 各 3×15 / 蟹步 20 步×3 |
| 第2周 | 每周 2 次 | 泡沫轴放松 + 髋屈肌拉伸 + ITB 拉伸 | 3 次 |
| 第3周 | 每周 3 次 | 弹力带侧抬腿 + 单腿硬拉 + 侧向平板支撑 | 各 3×12 / 平板 30 秒×3 |
| 第3周 | 每周 2 次 | 泡沫轴放松 + 臀肌泡沫轴按压 | 3 次 |
| 第4周 | 每周 3 次 | 弹力带蟹步走 + 单腿下蹲（扶墙）+ 侧平板抬腿 | 各 3×12 |

**要点**：力量训练比单纯拉伸更有效；每周 2-3 次臀中肌专项训练即可显著降低 ITBS 风险；田径场跑步时交替方向，避免单一弯道受力。

### 就医指南

**何时就医（红旗症状）**：
- 膝关节肿胀、积液明显
- 关节交锁（卡住不能活动）或弹响伴剧痛
- 膝关节不稳、打软腿
- 疼痛持续超过 2 周完全无改善
- 保守治疗 4-6 周症状反复或加重
- 无法负重行走

**就医时可能进行的检查**：
- 体格检查：Noble 试验、Ober 试验（评估髂胫束紧张度）、关节稳定性测试
- 超声检查：评估髂胫束厚度和炎症
- MRI：排除半月板撕裂、软骨损伤等关节内病变
- X 光：排除骨性病变（骨折、关节炎）

**建议询问医生的问题**：
- 我的疼痛是单纯的 ITBS，还是合并半月板等其他问题？
- 我的髂胫束是否过紧，是否需要专业手法放松？
- 臀中肌力量训练的强度和进度如何把握？
- 是否需要矫形鞋垫纠正足过度内旋？
- 估计多久能恢复正常训练和下坡跑？

**常见医疗处理（超出自我护理）**：
- 物理治疗：手法放松、超声波、电刺激消炎
- 局部注射：糖皮质激素注射（仅急性炎症期，不宜反复）
- 离心训练与步态矫正：由康复师指导
- 手术：极少数顽固性病例可行髂胫束松解术，非常规选择

### 季节与环境因素

**天气影响**：
- **冬季/低温**：髋外侧肌肉和髂胫束弹性下降，跑前需充分动态热身，可在室内先做蚌式开合激活臀中肌
- **夏季/高温**：出汗多易疲劳，疲劳后跑姿变形、骨盆侧倾加重，ITBS 易发作，注意控制跑量和补水
- **大风天**：逆风跑增加能耗、改变步态，间接加重膝外侧负荷

**跑步场地影响**：
- **下坡跑**：膝关节屈曲角度增大，髂胫束摩擦显著增加，是 ITBS 头号诱因，恢复期严禁
- **倾斜路面/路拱**：单侧路面倾斜使一侧腿内翻受力增加，长期跑同一侧路肩易引发 ITBS，应双向跑
- **田径场弯道**：单向跑使外侧腿受力更大，建议每次训练交替顺时针/逆时针
- **山地越野**：长下坡多，ITBS 风险高，需提前强化臀肌

**恢复期室内替代运动**：
- 游泳（自由泳）：零冲击，维持心肺，避免蛙泳（蹬腿可能刺激膝外侧）
- 骑行（室内单车）：低冲击，注意调整座椅高度避免膝过度屈曲
- 椭圆机：低冲击有氧，可调节阻力
- 划船机：全身有氧，对膝关节冲击小
- 室内力量训练：臀中肌、核心训练不仅不影响恢复，还能加速康复
- 水中跑步：零冲击模拟跑步，维持跑步特异性
