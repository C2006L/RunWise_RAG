# 跑者膝

## 核心概念

跑者膝（Runner's Knee），医学名称为髌股关节疼痛综合征（PFPS），是跑者最常见的膝关节损伤，约占跑步损伤的 20-25%。

### 解剖基础

**髌股关节**：髌骨（膝盖骨）与股骨滑车沟形成的关节。

**正常运动**：跑步时髌骨在滑车沟内上下滑动。

**问题发生**：当髌骨运动轨迹异常，与滑车沟摩擦增加，引发疼痛。

### 疼痛位置

- 髌骨下方或后方
- 髌骨内侧或外侧边缘
- 可能为双侧，也可能单侧

### 典型症状

- 疼痛在跑步中逐渐加重
- 下楼梯或下坡时疼痛明显
- 久坐后站起时膝部不适（"电影院征"）
- 膝关节屈曲时可能有摩擦音

## 常见问题

### 问题一：为什么会得跑者膝？

**四大原因**：

| 原因 | 机制 | 比例 |
|------|------|------|
| 股四头肌无力 | 髌骨轨迹不稳定 | 最常见 |
| 髌骨轨迹异常 | 髌骨向外侧偏移 | 常见 |
| 过度使用 | 跑量增加过快 | 常见 |
| 下肢力线异常 | 足外翻、Q角增大 | 部分跑者 |

**Q 角**：髂前上棘到髌骨中心，与髌骨中心到胫骨结节的夹角。女性 Q 角较大，因此跑者膝女性更常见。

### 问题二：怎么判断是跑者膝？

**诊断标准**：

1. 髌骨周围疼痛，定位不明确
2. 疼痛与活动相关（跑步、下楼梯加重）
3. 髌骨研磨试验阳性（按压髌骨同时屈伸膝）
4. 排除其他膝关节问题

**需要排除**：
- 髂胫束综合征（膝外侧明确痛点）
- 半月板损伤（关节间隙压痛、交锁）
- 髌腱炎（髌骨下方腱性组织压痛）
- 关节炎（年龄较大、晨僵）

### 问题三：还能继续跑吗？

**疼痛评分法**：

| 评分 | 建议 |
|------|------|
| 0-2/10 | 可继续跑，注意监控 |
| 3-5/10 | 减量 30-50%，避免下坡和速度训练 |
| 6-10/10 | 停止跑步，改为交叉训练 |

## 建议方案

### 急性期处理

1. **冰敷**：每次 15-20 分钟，每天 2-3 次
2. **休息**：停止或减少跑步
3. **非甾体抗炎药**：急性期可短期使用（遵医嘱）
4. **避免加重因素**：下楼梯、深蹲、下坡跑

### 康复训练

**股四头肌强化**：

1. **直腿抬高**：
   - 仰卧，一腿弯曲，另一腿伸直抬起 30 度
   - 保持 5 秒，缓慢放下
   - 每组 15-20 次，做 3 组

2. **终末伸膝**：
   - 坐姿，膝下垫毛巾卷
   - 小腿向上抬起，完全伸直膝
   - 每组 15-20 次，做 3 组

3. **靠墙静蹲**：
   - 背靠墙，膝弯曲 30-45 度
   - 保持 30-60 秒，做 3-5 次
   - 注意膝不超过脚尖

**髋外展肌强化**：

臀中肌无力会导致股骨内旋，增加髌骨外侧压力。

- 蚌式开合、侧抬腿（参见髂胫束综合征章节）

**髌骨松动术**：

- 坐姿，膝伸直
- 用手指推动髌骨上下左右滑动
- 每个方向 20-30 次，每天 2-3 次

### 足部问题处理

如果有明显足过度内旋：

- 选择支撑型或稳定型跑鞋
- 考虑定制足弓支撑
- 加强足内在肌力量（抓毛巾练习）

## 注意事项

1. **避免深蹲**：康复期间膝弯曲不超过 90 度
2. **循序渐进**：力量训练从低强度开始
3. **检查跑鞋**：磨损或类型不当可能加重问题
4. **不要只练股四头肌**：髋、踝力量同样重要

## 大学生场景案例

### 案例一：女生跑者反复膝痛

小王，女，大二，跑步半年后出现双膝疼痛。

**分析**：
- 女性 Q 角较大，髌骨轨迹易异常
- 股四头肌力量不足
- 跑鞋为普通运动鞋，缺乏支撑

**处理**：
- 更换稳定型跑鞋
- 每周 3 次股四头肌和臀中肌训练
- 6 周后疼痛明显缓解

### 案例二：下楼梯膝痛

小李，大三，平时跑步无痛，但下楼梯时膝前疼痛。

**诊断**：跑者膝早期表现。

**建议**：
- 虽然跑步无痛，但应开始预防性力量训练
- 避免跑量突增
- 下楼梯改为一步一阶，扶扶手

## FAQ

**Q：跑者膝需要拍片吗？**
A：通常不需要，临床诊断即可。如果怀疑其他问题（如半月板），医生会建议 MRI。

**Q：护膝有用吗？**
A：髌骨带或护膝可暂时缓解症状，但不能替代康复训练。

**Q：跑者膝会变成关节炎吗？**
A：跑者膝本身不会导致关节炎。但长期髌骨轨迹异常可能加速髌股关节退变。

**Q：多久能恢复？**
A：轻度 2-4 周，中度 4-8 周，重度可能需要 3 个月以上。坚持康复训练是关键。

使用 0-10 数字疼痛量表评估髌股关节疼痛程度，结合"红绿灯"系统指导训练决策。跑者膝以"下楼梯/久坐后站起"疼痛为特征，应同时评估日常活动疼痛。

| 评分 | 疼痛描述 | 红绿灯 | 行动指南 |
|------|----------|--------|----------|
| 0 | 完全无痛 | 🟢 绿灯 | 正常训练，保持股四头肌和臀肌训练 |
| 1 | 长距离后膝前轻微酸胀 | 🟢 绿灯 | 正常训练，跑后拉伸 |
| 2 | 久坐后站起轻微不适 | 🟢 绿灯 | 可继续跑，注意避免久坐不动 |
| 3 | 跑步中轻微疼痛，不影响配速 | 🟢 绿灯 | 减量，避免下坡和速度训练 |

| 5 | 跑步疼痛影响配速 | 🟡 黄灯 | 减量 50%，停速度训练和下坡 |
| 6 | 跑步后疼痛持续数小时 | 🟡 黄灯 | 改走跑结合，每天股四头肌训练 |

### 鉴别诊断速查

| 特征 | 跑者膝 | 髂胫束综合征 | 髌腱炎 | 半月板损伤 | 髌股关节炎 |
|------|--------|--------------|--------|------------|------------|
| 疼痛位置 | 髌骨周围/下方（弥漫） | 膝外侧（局限） | 髌骨下极腱 | 关节间隙 | 髌骨后方深部 |
| 疼痛性质 | 钝痛、酸胀 | 锐痛、刺痛 | 跳跃时刺痛 | 交锁、弹响伴痛 | 深部钝痛 |
| 出现时机 | 跑步中逐渐加重、久坐后 | 跑 2-3km 后 | 跳跃、上下楼 | 扭转、深蹲 | 持续、晨僵 |
| 电影院征 | 有（典型） | 无 | 可有 | 无 | 有 |
| 关节交锁 | 无 | 无 | 无 | 有 | 无 |
| 肿胀积液 | 通常无 | 无 | 可有局部肿 | 常有积液 | 可有 |
| 年龄倾向 | 各年龄 | 各年龄 | 年轻跑者 | 各年龄 | 年长者 |

**关键鉴别**：跑者膝与髂胫束综合征（ITBS）是膝痛两大主力——跑者膝是髌骨"周围弥漫性钝痛"、久坐后站起明显；ITBS 是膝外侧"局限性锐痛"、跑 2-3km 后才出现。两者康复重点也不同：跑者膝练股四头肌，ITBS 练臀中肌。

### 预防性力量训练计划

针对股四头肌、髋外展肌（臀中肌）和核心稳定性的 4 周预防计划。股四头肌和臀中肌无力是跑者膝的根本原因。

| 周次 | 频率 | 训练内容 | 组数×次数 |
|------|------|----------|-----------|
| 第1周 | 每周 3 次 | 直腿抬高 + 终末伸膝 + 靠墙静蹲 30 秒 | 各 3×15 / 静蹲 3×30 秒 |
| 第1周 | 每周 3 次 | 蚌式开合 + 侧抬腿（臀中肌） | 各 3×15 |
| 第2周 | 每周 3 次 | 直腿抬高（加踝沙袋）+ 终末伸膝（加弹力带）+ 靠墙静蹲 45 秒 | 各 3×15 / 静蹲 3×45 秒 |
| 第2周 | 每周 3 次 | 蚌式开合（加弹力带）+ 单腿臀桥 | 各 3×15 |
| 第3周 | 每周 3 次 | 单腿下蹲（扶墙，膝不超脚尖）+ 终末伸膝 + 靠墙静蹲 60 秒 | 各 3×12 / 静蹲 3×60 秒 |
| 第3周 | 每周 3 次 | 弹力带侧抬腿 + 侧向蟹步走 | 各 3×15 / 蟹步 20 步×3 |
| 第4周 | 每周 3 次 | 单腿下蹲（负重）+ 登台阶 + 靠墙静蹲 60 秒 | 各 3×12 |

**要点**：康复期间膝弯曲不超过 90 度，避免深蹲；力量训练从低强度开始循序渐进；女性 Q 角较大更需重视臀中肌训练；髋、踝力量同样重要，不可只练股四头肌。

### 就医指南

**何时就医（红旗症状）**：
- 膝关节肿胀、积液明显
- 关节交锁（卡住不能伸直或弯曲）或弹响伴剧痛
- 膝关节不稳、打软腿、突然"卡顿"
- 疼痛持续超过 2 周完全无改善
- 保守治疗 4-6 周症状反复或加重
- 无法负重行走

**就医时可能进行的检查**：
- 体格检查：髌骨研磨试验、髌骨推移、关节稳定性、Q 角测量
- X 光：排除骨性病变、评估髌骨位置和关节炎
- MRI：怀疑半月板撕裂、软骨损伤、韧带损伤时（金标准）
- 超声：评估髌腱和软组织

**建议询问医生的问题**：
- 我的疼痛是单纯的跑者膝，还是有半月板或软骨损伤？
- 我的髌骨轨迹是否异常，需要纠正吗？
- 股四头肌和臀肌力量训练的强度和进度如何把握？
- 是否需要护膝或髌骨带？
- 是否需要定制鞋垫纠正足过度内旋？
- 估计多久能恢复正常训练？

**常见医疗处理（超出自我护理）**：
- 物理治疗：髌骨松动术、超声波、电刺激、手法矫正髌骨轨迹
- 髌骨带/护膝：暂时缓解症状，不能替代康复训练
- 关节腔注射：玻璃酸钠注射（润滑关节），糖皮质激素（消炎，不宜反复）
- 定制鞋垫：针对足过度内旋
- 手术：极少数顽固性髌骨轨迹异常可行外侧松解术，非常规选择

### 季节与环境因素

**天气影响**：
- **冬季/低温**：膝关节滑液黏稠、肌肉弹性下降，跑前需充分动态热身 10 分钟，室内先做靠墙静蹲激活股四头肌
- **夏季/高温**：出汗多易疲劳，疲劳后股四头肌控制力下降、髌骨轨迹异常加重，注意控制跑量
- **湿冷天气**：关节僵硬感加重，可戴轻薄护膝保暖（仅保暖用途）

**跑步场地影响**：
- **下坡跑**：髌股关节压力显著增加（可达体重 7-8 倍），是跑者膝头号诱因，恢复期严禁
- **下楼梯**：同样高负荷，恢复期改一步一阶、扶扶手
- **硬地（水泥/柏油）**：冲击大，应避免，选择塑胶跑道
- **塑胶跑道/土路**：缓冲好，是恢复期首选
- **跑步机**：缓冲较好，可控制坡度（保持 0-1% 坡度，避免下坡模式）

**恢复期室内替代运动**：
- 游泳（自由泳）：零冲击，维持心肺；避免蛙泳（蹬腿增加膝外翻和髌股压力）
- 骑行（室内单车）：低冲击，注意座椅调高使膝弯曲不超过 90 度
- 椭圆机：低冲击有氧，模拟跑步动作
- 划船机：全身有氧，膝关节负荷小
- 室内力量训练：股四头肌、臀中肌、核心训练加速康复
- 水中跑步：零冲击模拟跑步，维持跑步特异性
