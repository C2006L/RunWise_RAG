# RunWise Web · 构图铁律（project_rules.md）

> 适用于全站视觉组装（Hero / 功能卡区 / 内容页装饰），违反任何一条即为视觉债务，M8 收口前必须清除。

## 铁律一：层级先行，倾斜做佐料

- 倾斜元素每屏 **≤2 处**（例外：Hero 拼贴标题的字母级微旋不计入，属 ransom-note 语言本体）
- 倾斜幅度一律 **≤3°**，全部引用 `--tilt-*` 令牌，禁止业务代码写死角度
- 禁止所有元素同时旋转——必须存在「锚点元素」（大卡、正文容器、表单）保持端正，让倾斜成为张力而非混乱

## 铁律二：可重叠装饰，不可遮挡内容

- 装饰素材（星星 / 闪电 / 网点 / 撕块 / 胶带）允许跨容器边界、互相重叠
- **文字与可交互控件（按钮 / 输入框 / 链接）不得被任何元素盖住**；确需视觉交叠时，内容层 z-index 必须高于装饰层
- 装饰元素一律 `pointer-events: none` 或 `aria-hidden`，不干扰交互与读屏

## 铁律三：面积与密度成正比

- 大面积容器（大卡 / Hero）必须填充足够密度的内容与装饰，禁止大面积留白
- 小元素保持疏朗——星星 / 闪电只出现在角落与空隙，不堆叠
- 装饰密度随面积递增：Hero（撕块+星×3+网点×2）> 大卡（编号+进度条+CTA）> 小卡（编号+标题）
